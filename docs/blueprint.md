# **App Name**: Product Asset Uploader

## Core Features:

- Product Info Form: Form to capture product title, category, and tags.
- Multi-Image Uploader: Component to upload up to 3 images, display previews, and allow deletion.
- Submission and Feedback: Submit button with simulated saving loader and success toast.

## Style Guidelines:

- Primary color: Neutral grays for a professional feel.
- Secondary color: White for clean backgrounds.
- Accent: Teal (#008080) for interactive elements and highlights.
- Desktop: Side-by-side layout for form and images.
- Mobile: Stack form and images vertically.
- Subtle loading animations and transitions for smooth interaction.
